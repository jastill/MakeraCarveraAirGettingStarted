# Quick Start Guide - Carvera Air

## 15-Minute Setup Checklist

### 📦 Unboxing (5 minutes)
- [ ] Remove machine from packaging
- [ ] Check all components are present
- [ ] Remove protective materials
- [ ] Place on stable surface

### 🔌 Connections (3 minutes)
- [ ] Connect power adapter
- [ ] Connect USB cable to computer
- [ ] Power on machine
- [ ] Wait for homing sequence

### 💾 Software (5 minutes)
- [ ] Download Carvera software
- [ ] Install and launch
- [ ] Connect to machine
- [ ] Update firmware if prompted

### ✅ First Test (2 minutes)
- [ ] Load "Hello World" example
- [ ] Run air simulation
- [ ] Verify all axes move correctly

## Your First 30 Minutes

1. **Complete setup checklist above**
2. **Read safety guidelines** (docs/safety.md)
3. **Try the basic engraving example** (examples/01-basic-engraving)
4. **Join the community forum** for questions and tips

## Essential Safety Rules

⚠️ **ALWAYS wear safety glasses**
⚠️ **Never leave machine unattended while running**
⚠️ **Keep emergency stop accessible**
⚠️ **Secure workpiece properly before cutting**
