# Troubleshooting Guide

## Common Issues and Solutions

### Machine Won't Power On

**Symptoms:**
- No lights or display
- No response when power button pressed
- No movement when connected

**Solutions:**
1. Check power adapter connection
2. Verify power outlet is working
3. Try different power outlet
4. Check for damaged power cable
5. Contact support if power adapter appears faulty

### Software Can't Detect Machine

**Symptoms:**
- "Machine not found" error
- Software shows "Disconnected"
- USB device not recognized

**Solutions:**
1. **Check USB Connection:**
   - Try different USB cable
   - Use different USB port
   - Avoid USB hubs - connect directly

2. **Driver Issues:**
   - Reinstall device drivers
   - Check Device Manager (Windows)
   - Update USB drivers

3. **Software Issues:**
   - Restart software
   - Run as Administrator (Windows)
   - Reinstall software if needed

### Poor Cut Quality

**Symptoms:**
- Rough or torn edges
- Burn marks on material
- Chatter marks
- Dimensional inaccuracy

**Solutions:**

#### Rough Edges
- Check tool sharpness
- Reduce feed rate
- Use climb milling when possible
- Ensure proper tool for material

#### Burn Marks
- Increase feed rate
- Reduce spindle speed
- Improve chip evacuation
- Use coolant or air blast

#### Chatter
- Reduce tool overhang
- Decrease depth of cut
- Check workholding rigidity
- Use shorter, more rigid tools

### Tool Breakage

**Symptoms:**
- Sudden loud noise
- Machine stops unexpectedly
- Broken tool pieces in workspace

**Immediate Actions:**
1. Press emergency stop
2. Turn off spindle
3. Wait for all motion to stop
4. Carefully remove broken pieces
5. Inspect for damage

**Prevention:**
- Use appropriate speeds and feeds
- Don't exceed tool manufacturer's recommendations
- Check tool condition before use
- Ensure proper workholding
- Avoid taking too heavy cuts

### Machine Making Unusual Noises

**Types of Noises and Causes:**

#### High-pitched squealing
- Spindle bearings worn
- Tool rubbing
- Insufficient lubrication

#### Grinding or scraping
- Debris in linear bearings
- Axis binding
- Foreign object in machine

#### Rhythmic knocking
- Loose coupling
- Worn ball screw
- Unbalanced tool

**Actions:**
1. Stop machine immediately
2. Power down and disconnect
3. Visually inspect for obvious problems
4. Contact support for unusual noises

### Workpiece Movement During Cutting

**Symptoms:**
- Parts shift position
- Inconsistent cut depth
- Tool marks show movement

**Solutions:**
1. **Improve Workholding:**
   - Use more clamps
   - Position clamps closer to cut area
   - Use different workholding method

2. **Reduce Cutting Forces:**
   - Lower feed rates
   - Reduce depth of cut
   - Use sharp tools
   - Consider climb milling

3. **Add Tabs:**
   - Leave small connections to hold parts
   - Remove tabs after cutting

### Software Crashes or Freezes

**Symptoms:**
- Software becomes unresponsive
- Frequent crashes during operation
- Error messages

**Solutions:**
1. **System Resources:**
   - Close other applications
   - Check available RAM
   - Monitor CPU usage

2. **Software Issues:**
   - Update to latest version
   - Clear application data
   - Reinstall software
   - Check system requirements

3. **File Issues:**
   - Try different project file
   - Simplify complex models
   - Check file corruption

### Dimensional Inaccuracy

**Symptoms:**
- Parts too large or small
- Holes wrong size
- Features not matching design

**Solutions:**
1. **Check Tool Diameter:**
   - Verify actual vs. programmed diameter
   - Measure tools with micrometer
   - Update tool library

2. **Machine Calibration:**
   - Run calibration routine
   - Check axis scaling
   - Verify encoder feedback

3. **Material Issues:**
   - Account for material expansion/contraction
   - Check material thickness
   - Consider spring-back in materials

### Emergency Situations

#### Tool Breaks and Continues Cutting
1. **IMMEDIATELY** press emergency stop
2. Power down machine
3. Assess damage before restarting
4. Replace broken tool
5. Check part for damage

#### Smoke or Burning Smell
1. **IMMEDIATELY** stop operation
2. Turn off spindle
3. Check for fire
4. Investigate cause before continuing
5. Have fire extinguisher ready

#### Machine Runs Away (Unexpected Movement)
1. **IMMEDIATELY** press emergency stop
2. Power down machine
3. Do not attempt to restart
4. Check all connections
5. Contact technical support

## Maintenance-Related Issues

### Regular Maintenance Schedule

**Daily (After Each Use):**
- Clean work area of chips and debris
- Wipe down machine surfaces
- Check for loose tools or parts

**Weekly:**
- Clean linear guides and ways
- Check belt tension
- Inspect cutting tools
- Verify emergency stop operation

**Monthly:**
- Lubricate per manufacturer's schedule
- Check all fasteners for tightness
- Inspect electrical connections
- Update software if needed

**Quarterly:**
- Deep clean entire machine
- Calibrate machine accuracy
- Inspect wear parts
- Professional service if needed

### When to Contact Support

Contact technical support when:
- Safety systems don't function properly
- Unusual noises persist after basic troubleshooting
- Repeated software crashes
- Accuracy problems persist after calibration
- Any electrical issues or sparks
- Machine movement seems abnormal

### Diagnostic Information to Collect

When contacting support, have ready:
- Machine serial number
- Software version
- Operating system version
- Description of problem
- Steps taken to reproduce issue
- Any error messages or codes
- Photos or videos of the issue
