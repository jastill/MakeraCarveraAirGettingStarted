## What's in the Box

Your Carvera Air package should include:
- Carvera Air CNC machine
- Power adapter and cable
- USB cable for computer connection
- Tool holder and basic cutting tools
- Clamps and workholding accessories
- Safety glasses
- Quick start guide
- Software installation media/download instructions

## Initial Setup

### 1. Unboxing and Inspection
1. Carefully remove the Carvera Air from its packaging
2. Check that all components are present (see list above)
3. Inspect the machine for any shipping damage
4. Remove any protective foam or tape from moving parts

### 2. Physical Setup
1. Place the machine on a stable, level surface
2. Ensure adequate clearance around the machine (minimum 12" on all sides)
3. Connect the power adapter
4. Connect the USB cable to your computer

### 3. Initial Power-On
1. Press the power button
2. The machine will perform an automatic homing sequence
3. Wait for the initialization to complete (LED indicators will show ready status)

## Software Installation

### Requirements
- Windows 10/11, macOS 10.14+, or Linux Ubuntu 18.04+
- Minimum 4GB RAM, 8GB recommended
- 2GB available storage space
- USB 2.0 or higher port

### Installation Steps
1. Download the latest Carvera software from [Makera's website](https://makera.com)
2. Run the installer and follow the setup wizard
3. Connect your Carvera Air via USB
4. Launch the software and complete the machine detection process
5. Download and install any firmware updates if prompted

## Your First Project

Start with this simple "Hello World" project to verify everything is working:

### Project: Engraving a Simple Design

**Materials Needed:**
- Piece of soft wood (pine or basswood, 3" x 3" x 0.5")
- Small engraving bit (included with machine)

**Steps:**
1. Secure the wood piece using the provided clamps
2. Insert the engraving bit into the tool holder
3. Open the Carvera software and create a new project
4. Use the text tool to add "HELLO WORLD"
5. Set material thickness and tool parameters
6. Generate the toolpath
7. Run the simulation to verify the cut
8. Start the cutting process

**Safety Note:** Always wear safety glasses and ensure the workspace is clear before starting any cut.

## Safety Guidelines

⚠️ **IMPORTANT: Read these safety guidelines before operating your Carvera Air**

### Before Each Use
- [ ] Inspect all clamps and workholding
- [ ] Verify tool is properly secured
- [ ] Check that workspace is clear of debris
- [ ] Ensure safety glasses are worn
- [ ] Confirm emergency stop is functional

### During Operation
- Never leave the machine unattended while cutting
- Keep hands and loose clothing away from moving parts
- Do not open the enclosure while machine is running
- Monitor cutting progress for any unusual sounds or behaviors

### After Use
- Allow spindle to come to complete stop
- Remove all debris from work area
- Store tools properly
- Power down the machine

## Troubleshooting

### Common Issues

**Machine won't power on:**
- Check power adapter connection
- Verify power outlet is working
- Try a different USB cable

**Software can't detect machine:**
- Ensure USB cable is properly connected
- Try a different USB port
- Restart both software and machine
- Check for driver updates

**Poor cut quality:**
- Check tool sharpness
- Verify proper speeds and feeds
- Ensure material is properly secured
- Check for excessive vibration

**Machine makes unusual noises:**
- Stop operation immediately
- Check for loose parts or debris
- Inspect tool holder and spindle
- Contact support if issues persist
